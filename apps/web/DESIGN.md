# 赴约公开前端设计规范

## 产品位置

赴约是面向本体恋与 AIRP 的 LocalData-first 简易小手机，不模拟完整操作系统。公开仓提供完整的视觉、动效与操作源码，并从空白人物和空白 LocalData 开始。

## 导航与交互

- 底栏固定为：首页、聊天、一起、书房、房间。
- 左上角是可搜索的全功能抽屉，覆盖当前公开能力的每一类去向；能当地工作的直达，需要 relay、原生授权或独立房间包的显示“待接 / 待装”和真实条件。右上角只是外观捷径，不承担功能发现。
- 首页是连续生活的恢复面：在场、继续上次、下一项日程、2–4 个手边入口、陪伴者可见心情和本地副本。
- 聊天直接进入消息时间线，不重复摆放页面大标题。聊天页占满当前可见高度，只让消息区内部滚动；输入框不能被长记录或手机键盘推出视口。软键盘升起时暂时收起顶栏和五栏，把可见高度让给消息与输入；键盘收起后自动恢复。未连接 relay 时仍可手工记录双方原文；连接后流式回复进入同一账本。
- 一起使用「今天 / 一起做 / 课表」直接式分段，入口单击进入。
- 透明叠条只用于书房与房间：点一次在原位置浮起，不改变卡片顺序；再点一次进入。搜索和分区不改变这个语法。
- 所有二级页面进入浏览器历史；界面返回和系统返回都回到原处。返回栏在长页面内吸顶，不要求使用者滑回顶部。没有实现的后端能力进入诚实空态或连接页，不放死按钮。

## 视觉

- 延续纸页、低彩度线条、宋体标题、轻微不对称圆角和统一线性图标；不复刻任何官方客户端。
- 底纸与重点色分开：六套重点色都能独立切换白天/黑夜；默认红叶纸的白天版本。
- 深色重点面使用重点色的深阶，不把高权重卡片固定为纯黑。
- 环境效果沿用 Chat Ambience 的运动模型和成品矢量：雪、雨、爱心、树叶各自下落，蝴蝶横向飞，星屑短暂生灭，泡泡上浮后胀破，萤火无规则游走，猫爪沿路径交替留下脚印。羽毛与纸鹤已经退役；星屑和萤火会自动进入黑夜，但仍跟随当前重点色。
- 正文与占位文字达到可读对比；触控目标至少 44px；输入框在手机上至少 16px，避免 iOS 聚焦放大。
- 卡片只在内容需要承载边界时出现；今天、一起做和设置项优先使用直接行列。

## 动效

- 高频底栏切换使用 260ms 的轻位移、淡入和短暂 blur；按压反馈 140ms。
- 叠条使用 260ms 强 ease-in-out；选中的卡只在原位上浮 8px，其他卡和整叠顺序不移动。
- 二级页面使用 300ms 上移与 clip-path 展开，系统返回同步退出页面状态。
- `prefers-reduced-motion: reduce` 时跳过位移、blur、clip-path 和循环动效。

## 数据与后端边界

- 人物、原文、记忆和外观默认只写入浏览器 IndexedDB / localStorage。
- 前端只连接一个用户自建 relay，不存供应商 API Key。
- 只有用户主动发送的一轮、两份人物资料与明确启用召回的记忆进入 relay。
- provider 列表来自 `GET /v1/status`，没有真实端点的模型不显示。
- 日程和可见心情来自明确接口；离线时不使用演示数据冒充真实生活或隐藏内心。
- 具体请求、流事件、错误与取消契约见 `docs/RELAY_API_CONTRACT.md`。
