# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Users

- 想把一个长期陪伴者连同人物、原文、记忆、房间与外观完整带走的使用者。
- 只想采用某一块界面、交互、数据契约或可选服务的开发者。
- 不想运维服务、但愿意填入自己的模型与语音 API Key 的普通使用者。

## Product Purpose

赴约是一个 LocalData-first 的长期陪伴家园。它把聊天原文、人物、记忆、房间记录、玩具与外观放在使用者自己的设备上，并通过明确的导出、导入与可选协议让“整家带走”和“只拿一块”同时成立。

## Positioning

陪伴者不只返回文字。只有在使用者明确要求下，它才能通过白名单本机工具改动自己的签名、心情、待审记忆、共同房间记录、外观或单文件小玩具；每次变化都必须有数据回读、页面结果与审计痕迹。没有真正执行工具时，产品不得显示“已完成”。

## Operating Context

- 普通 PWA 在浏览器中使用 IndexedDB / localStorage，只能声称浏览器真正提供的能力。
- Android 壳使用系统权限、Calendar Provider 与 Keystore；密钥不进前端、LocalData、导出或 Git diff。
- 模型连接、语音、设备授权、媒体来源与可选功能包是不同任务，不互相冒充已完成。
- 用户可选整家一键配置，也可单独带走视觉外壳、开屏、排布、环境漂浮物、旅行前端、记忆契约或单项能力。

## Capabilities and Constraints

- 人物、原文、记忆、房间、玩具、玩具活动与外观默认是本机数据，并进入可携带快照。
- 玩具盒是房间内的本机功能，不依赖业务后端；玩具在无同源权限、无网络权限的沙箱中运行。
- Agent 工具是有界的产品操作，不是 shell、任意网络、任意文件或未审记数据库权限。
- 语音链路只有真实厂商转写、同一聊天模型、真实合成与同一原文账本都有证据时才标成真实通过；文字试通话不冒充 ASR。
- 完全隐藏只移除普通入口，不删除资料，且必须可从功能包恢复。
- 发布包不带入用户数据、个人名字、生产地址、Cookie、供应商 Key 或内部提示。

## Brand Commitments

- 产品名为“赴约”；公开源码保留完整的家的结构、视觉、动效与操作。
- 底部五栏固定为首页、聊天、一起、书房、房间；视觉世界沿用现有纸页、低彩度线条、宋体标题、轻微不对称圆角与环境动效。

## Evidence on Hand

- 公开候选已有 LocalData、relay 契约、Android 壳、功能包装配和浏览器 / 真机验收脚本。

## Product Principles

1. 没有数据写入与读回证据，就没有完成。
2. 整家可携带，每块也能独立装配。
3. 陪伴者可以动手，但权限最小、结果可见、失败诚实、全程可审计。
4. 公开前端不回收私密，不把模拟、契约或空壳写成真实运行。
5. 恢复、返回、刷新、导出与重开是功能的一部分。

## Accessibility & Inclusion

入口与玩具必须可键盘操作，触控目标至少 44px，表单有明确标签，动效尊重 `prefers-reduced-motion`，窄屏与软键盘不遮挡主要操作。
