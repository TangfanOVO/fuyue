# Ambient icon sources

The ambient particle SVG variants in `apps/web/src/ambient-shapes.ts` were
exported from the Iconify API. The original handoff records the following
upstream collection prefixes:

- `mdi`
- `tabler`
- `lucide`
- `carbon`
- `charm`
- `solar`
- `icon-park`
- `uil`
- `meteor-icons`
- `boxicons`
- `octicon`
- `mingcute`
- `teenyicons`

The particle motion, composition and interface are part of Fuyue. The SVG
geometry is third-party material and remains under each upstream collection's
license; it is not relicensed under Fuyue's AGPL license.
