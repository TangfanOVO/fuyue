## 后台行为不会靠文案冒充

- 公开版记忆当前是手动账本：新建为待审草稿，使用者明确启用后才随发送注入。`/distill`、`/review` 与事件路由声明不等于自动引擎已经运行。
- 公开版心情只读取后端明确返回的快照；没有后端事件时不会随机加减。“碰一碰”是手工生活记录，不是自动心潮。
- 已经随包可用的本地能力会直接启用，不生成工作单；只有仍需外部实现的选择才生成 `fuyue-build-plan` 和共同工作本待办。手机端不会谎称已经拉取仓库或写完后端。
- 完全隐藏会真正撤掉首页、书房、房间和抽屉入口，但不删除以前资料；功能包保留恢复入口。只有入口和开放契约的功能会标成“前端与协议已带”，不冒充已有运行后端。
- 聊天和电话共用同一组受限本机工具；伙伴可以按明确请求写信箱、时间线、工作本、日记、修补本和碰一碰，也可以偶尔留下自己的碎碎念，但不能冒充用户、执行 shell 或绕开审阅把记忆直接升格。
